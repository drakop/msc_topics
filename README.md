# msc_topics

List of available MSc topics.

The list contains the following documents, each containing MSc topics per graduate program per academic year. The topics pertain to machine learning, graph mining, and linear algebra applied to humanistic data mining including among others social network analysis, smart cities, financial engineering, data storytelling, and computational psychology.
*  acs_2026.pdf
*  acs_2025.pdf
*  [ddcdm_2022](https://github.com/drakop/msc_topics/blob/main/ddcdm_2022.pdf)
*  [ddcdm_2021](https://github.com/drakop/msc_topics/blob/main/ddcdm_2021.pdf)

The graduate programs listed above are the following.
*  **ACS:** _Advanced Computing Systems_. ICE, University of West Attica, Greece.
*  **DDCDM:**  _Decision Driven Computing and Decision Making_. CEID, University of Patras, Greece.
